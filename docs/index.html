MilliHash API (v1.0.0)

Download OpenAPI specification:

Product MilliHash REST API — all product-owned controllers documented per cross-cutting/api-contracts (includes operator admin; excludes Actuator/springdoc).

MilliHash runs as two deployments against the same database:

  • Free instance — production public edge https://free-api.millihash.io (first-party SPA Free mode). Logical third-party direct host api.millihash.com also serves unauthenticated public verification. RapidAPI-authenticated routes (POST/GET /registrations, certificate download) are disabled on the free deployment.
  • Pro instance — reachable only through the RapidAPI proxy (https://millihash.p.rapidapi.com, X-RapidAPI-Host: millihash.p.rapidapi.com). Serves RapidAPI-authenticated registration, project, owner-portfolio, and FR21 similarity (overlap / watches / alerts) routes, plus every public verification and similarity search/sample route, so RapidAPI subscribers can call the whole API with one key.

Authenticated endpoints require X-RapidAPI-Key (pro instance / RapidAPI ingress only).

Public verification endpoints require no authentication on the free instance and are also available to RapidAPI subscribers on the pro instance, with identical responses.

Operator admin (GET /admin/audit) is documented below for completeness. It is served on app.millihash.com with Auth0 JWT — not via RapidAPI or the public free/direct API edge.

Registrations

Asset hash registration (pro / RapidAPI only)

Register an asset hash with RFC 3161 TSA timestamp

Synchronous registration pipeline: resolve typed proof digests (or accept client-supplied hash as client-supplied-v1), compute VersionCommitment (contentHash), acquire TSA token over that commitment, enforce per-registrant uniqueness per proof digest (the same registrant re-registering a proof digest is rejected; a different registrant succeeds with a prior-registration notice), persist Registration, enqueue AnchorJob. Asset bytes are never stored. Client-supplied mode accepts hash hex only (no file upload). Optional immutable label; optional labelPublic (default false); optional internalLabel (owner-only).

Owner Portfolio

Owner registry, projects, and certificate download (pro / RapidAPI only)

List Registrations owned by the authenticated user

Owner-scoped, cursor-paginated registry dashboard. Fixed page size 50. Default sort: tsaTimestamp descending, registrationId ascending tie-break. Optional sort: label (display-name semantics: internalLabel then label; default ascending), bitcoinBlockConfirmationTime (default descending), or tsaTimestamp. Optional direction: asc or desc (defaults per sort field). Tie-break is always registrationId ascending. Missing on-chain times follow MongoDB null ordering (first on asc, last on desc). Listing does not invoke per-row anchor lookup. Rows include digests, label, labelPublic, internalLabel, and displayName.

Get public activity stats

Aggregate service activity for display on public pages. timestampStandard and anchoring are always returned. latestAnchorConfirmedAt is returned only when a Bitcoin anchor confirmed recently, and each usage field only once it reaches a server-side threshold; omitted fields are absent rather than zero. Never returns hashes, labels, registrant data, or per-registration identifiers. The sample proof is excluded from all counts. Responses are cached for up to 60 seconds.
