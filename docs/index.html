MilliHash API (v1.0.0)

Download OpenAPI specification:

MilliHash REST API for asset registration, verification, project lineage, portfolio management, and opt-in similarity search.

Hosts

  • https://free-api.millihash.io — public verification, stats, and sample proof
  • https://millihash.p.rapidapi.com — authenticated registration, portfolio, projects, similarity, plan, plus the same public verification routes
  • https://app.millihash.com — operator admin audit (Auth0 JWT)

Authenticated routes require X-RapidAPI-Key. Public verification routes require no auth.

Registrations

Register assets and refresh discovery fingerprints

Register an asset

Hash the asset (or accept a client-supplied SHA-256), timestamp a version commitment with RFC 3161 TSA, persist the registration, and enqueue Bitcoin anchoring.

  • JSON — text (text) or client-supplied (hash); no body contentType.
  • Multipart — required file + optional mediaType (sniff if omitted).
  • Asset bytes are never stored — only digests and metadata.
  • Same proof digest by the same caller → 409; other callers may succeed with a prior-registration notice.

Refresh discovery fingerprints

Re-upload the original asset for a registration you own. Proof digests, version commitment, and original TSA stay unchanged. On success, MilliHash adds discovery fingerprints, advances fingerprintSetVersion, and creates a separately timestamped / anchored FingerprintRefresh.

  • JSON — { "text": "..." } for text registrations.
  • Multipart — file + optional mediaType.
  • Proof match required (any overlapping proof hex); else 409 PROOF_HASH_MISMATCH.
  • Does not consume registration quota.

Cursor-paginated registry of registrations you own (page size 50). Default sort: tsaTimestamp descending. Optional sort / direction; tie-break is always registrationId ascending. Rows include digests, labels, display name, and anchor state (no per-row anchor lookup).

Similarity Search

Opt-in semantic text similarity search and samples

Search similar registrations

Embed the query and return ranked opted-in registrations as similarity candidates.

  • Your own registrations can appear as normal rows (isOwn).
  • In idea mode, other users' hidden hits contribute only to privateMatchCount.
  • In wording mode, those hidden hits are omitted entirely.
  • Query text is normalized (text-normalized-v2) before size checks and embedding.
  • Page with limit (default 10, max 50) and cursor from a prior nextPageCursor.
Authorizations:
RapidApiKey
Request Body schema: application/json
required
query
required
string

UTF-8 search text. Blank → 400 QUERY_EMPTY. Size limited by plan maxSimilarityQuerySize after normalization.

mode
string
Default: "idea"
Enum: "idea" "wording"

idea — semantic / topical similarity (lower cosine floor). wording — near-duplicate wording (higher cosine floor); drops others' hidden matches.

includeSamples
boolean
Default: false

When true, include MilliHash sample documents in the candidate pool.

limit
integer [ 1 .. 50 ]
Default: 10

Max rows in this page.

minCosine
number [ 0 .. 1 ]

Optional cosine floor for a hit. When omitted, idea uses ~0.82 and wording uses ~0.95.

cursor
string

Opaque cursor from a previous nextPageCursor for the next page.
